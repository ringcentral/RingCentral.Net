All records in response are sorted by creation time of a chat in ascending order.

{\bfseries{Chat types}}

There are multiple types of chats, including\+:


\begin{DoxyItemize}
\item {\bfseries{Personal}} -\/ each user is given a dedicated "{}personal chat"{} in which they are the only member.
\item {\bfseries{Direct}} -\/ a chat between two individuals.
\item {\bfseries{Group}} -\/ a chat between three or more named individuals. A "{}group"{} chat has no name.
\item {\bfseries{Team}} -\/ a chat related to a specific topic. Members can come and go freely from this chat type.
\item {\bfseries{\doxylink{namespaceRingCentral_1_1Paths_1_1TeamMessaging_1_1V1_1_1Everyone}{Everyone}}} -\/ a special chat containing every individual in a company.
\end{DoxyItemize}
