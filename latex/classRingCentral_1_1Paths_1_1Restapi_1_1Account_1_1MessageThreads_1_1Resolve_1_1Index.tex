Resolves a message thread (sets the status to {\ttfamily Resolved}). The current status of the thread must be {\ttfamily Open} for this operation to succeed. The authorized user must be in the list of thread monitors, otherwise the API returns a 403 error. 

Once the thread is resolved its {\ttfamily assignee} attribute is cleared automatically.
