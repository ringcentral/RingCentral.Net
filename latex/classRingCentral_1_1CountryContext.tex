\doxysubsection{Detailed Description}
Country context definition. 

{\bfseries{In the request}}\+:

Country context can be identified by {\ttfamily country.\+iso\+Code} value only\+:
\begin{DoxyItemize}
\item If the value is not specified, it\textquotesingle{}s taken from the context source\+:
\begin{DoxyItemize}
\item {\ttfamily Default} -\/\texorpdfstring{$>$}{>} {\ttfamily null}
\item {\ttfamily Account} -\/\texorpdfstring{$>$}{>} home country of the requester\textquotesingle{}s account
\end{DoxyItemize}
\item Explicitly set value redefines the value taken from the context source.
\item Explicitly set {\ttfamily null} value disables country context for parsing.
\end{DoxyItemize}

{\bfseries{In the response}}\+:

Country context is returned with additional attributes.

{\bfseries{In particular result items}}\+:

Country attribute is absent for the {\ttfamily results.\+category} response\textquotesingle{}s attribute values\+: {\ttfamily Unknown} and {\ttfamily Extension}.
