Returns a list of supported features and the information on their availability for the current extension. Particular feature(s) can be checked by providing {\ttfamily feature\+Id} query parameter. Multiple values are supported in the format\+: {\ttfamily ?feature\+Id=Feature1\&feature\+Id=Feature2}. To get only available features in order to decrease response size, {\ttfamily available\+Only=true} query param can be specified. If a feature is available for the current user, {\ttfamily "{}available"{}\+: true} is returned in response for the record with the corresponding feature ID. Otherwise, the additional attribute {\ttfamily reason} is returned with the appropriate code\+: 


\begin{DoxyItemize}
\item {\ttfamily Service\+Plan\+Limitation} -\/ a feature is not included in account service plan;
\item {\ttfamily Account\+Limitation} -\/ a feature is turned off for account;
\item {\ttfamily Extension\+Type\+Limitation} -\/ a feature is not applicable for extension type;
\item {\ttfamily Extension\+Sub\+Type\+Limitation} -\/ a feature is not applicable for extension sub-\/type;
\item {\ttfamily Extension\+Limitation} -\/ a feature is not available for extension, e.\+g., additional license required;
\item {\ttfamily Insufficient\+Permissions} -\/ required permission is not granted to the current user (not the one, who is specified in the URL, but the one who is calling this API);
\item {\ttfamily Configuration\+Limitation} -\/ a feature is turned off for extension, e.\+g., by account administrator.
\item {\ttfamily Permission\+Limitation} -\/ a feature is unavailable due to a specific permission this extension has.
\end{DoxyItemize}
