Synchronizes the list of thread entries. The response may contain\+: 


\begin{DoxyItemize}
\item added or updated messages (full payload);
\item added or updated notes (full payload);
\item deleted message entries (limited attributes, {\ttfamily availability} is set to {\ttfamily Deleted});
\item deleted note entries (limited attributes, {\ttfamily availability} is set to {\ttfamily Deleted});
\item system entries ({\ttfamily action} describes the action performed).
\end{DoxyItemize}

In {\ttfamily FSync} model\+:
\begin{DoxyItemize}
\item only {\ttfamily Alive} messages and notes are returned;
\item only messages and notes from {\ttfamily Open} threads are returned (unless explicit {\ttfamily thread\+Ids} are requested).
\end{DoxyItemize}

The records are sorted by {\ttfamily last\+Modified\+Time} in descending order.
