Returns access (and potentially refresh) tokens for making API requests. 

For confidential client application types this endpoint requires client authentication using one of the supported methods\+:
\begin{DoxyItemize}
\item {\ttfamily client\+\_\+secret\+\_\+basic} -\/ client ID and client secret must be provided via {\ttfamily Authorization} header as described in \href{https://datatracker.ietf.org/doc/html/rfc6749\#section-2.3.1}{\texttt{RFC-\/6749}}.
\item {\ttfamily client\+\_\+secret\+\_\+jwt} / {\ttfamily private\+\_\+key\+\_\+jwt} -- {\ttfamily client\+\_\+assertion} attribute should be used to pass a signed JWT as described in \href{https://datatracker.ietf.org/doc/html/rfc7523\#section-2.2}{\texttt{RFC-\/7523}}.
\end{DoxyItemize}

For non-\/confidential client application types the client identifier must be provided via {\ttfamily client\+\_\+id} request attribute.
