Creates and sends a new message to one or more recipients. 

The message is automatically attached to the thread specified in the {\ttfamily thread\+Id} parameter. If {\ttfamily thread\+Id} is omitted, it is routed to the matching thread based on the {\ttfamily from} and {\ttfamily to} phone numbers; a new thread is created automatically when no matching thread exists.

The endpoint accepts two request formats\+:
\begin{DoxyItemize}
\item {\ttfamily application/json} -\/ for text-\/only messages.
\item {\ttfamily multipart/form-\/data} -\/ to send a message together with one or more binary attachments (for MMS / rich messages). Put the message fields in the {\ttfamily metadata} part and each file in an {\ttfamily attachments} part, as shown in the example below.
\end{DoxyItemize}

Note\+: a suggested attachment filename is optional; when needed, provide it via the {\ttfamily filename} field in the {\ttfamily Content-\/\+Disposition} header.
