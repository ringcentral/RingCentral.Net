Do Not Disturb status. Not applicable for \doxylink{classRingCentral_1_1User}{User} extensions if the new communication handling service is activated on account. 

Please note\+: Cannot be set for Department/\+Announcement/\+Voicemail (Take Messages Only)/\+Fax User/\+Shared Lines Group/\+Paging Only Group/\+IVR Menu/\+Application Extension/\+Park Location extensions.

The \textquotesingle{}Do\+Not\+Accept\+Department\+Calls\textquotesingle{} and \textquotesingle{}Take\+Department\+Calls\+Only\textquotesingle{} values are applicable only for extensions -\/ members of a Department; if these values are set for department outsiders, the 400 Bad Request error code is returned.

The \textquotesingle{}Take\+Department\+Calls\+Only\textquotesingle{} status can be set through the old \doxylink{namespaceRingCentral}{Ring\+Central} user interface and is available for some migrated accounts only.
