bool? Ring\+Central.\+Bridge\+Request\+Security.\+password\+Protected\hspace{0.3cm}{\ttfamily [get]}, {\ttfamily [set]}}



Specifies if a meeting is password protected. 

By default, {\ttfamily Instant} and {\ttfamily Scheduled} bridges are not password protected. For default (PMI) bridge, password protection will be turned on and the password will be generated if it is not specified while creation.

While creation to set password protection you should set this field to true and specify a password in the {\ttfamily \doxylink{classRingCentral_1_1BridgeRequestSecurity_a1d8f04490a454ba4b4191b1c54ac33b8}{password}} field. If you want to change password or set password protection for an unprotected bridge, you should set this field to true and specify a password in the {\ttfamily \doxylink{classRingCentral_1_1BridgeRequestSecurity_a1d8f04490a454ba4b4191b1c54ac33b8}{password}} field in the update operation.

To make protected bridge as unprotected you should set this field to false in the update operation. Example\+: true
