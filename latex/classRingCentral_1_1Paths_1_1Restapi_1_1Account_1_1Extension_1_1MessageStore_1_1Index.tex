Patches message(s) by ID(s). Currently, only updating the {\ttfamily read\+Status} and restoring deleted messages are supported through this method. 

For changing status of a message send {\ttfamily read\+Status} set to either \textquotesingle{}Read\textquotesingle{} or \textquotesingle{}Unread\textquotesingle{} in request. It is possible to restore a message and its attachments (if message status is \textquotesingle{}Deleted\textquotesingle{}) by sending {\ttfamily availability} attribute set to \textquotesingle{}Alive\textquotesingle{} in request body. If a message is already in \textquotesingle{}Purged\textquotesingle{} state then its attachments cannot be restored and the message itself is about to be physically deleted.

Bulk syntax (both traditional and alternative one) is supported.
