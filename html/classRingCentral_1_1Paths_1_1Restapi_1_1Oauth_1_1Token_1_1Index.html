Returns access (and potentially refresh) tokens for making API requests.

For confidential client application types this endpoint requires client authentication using one of the supported methods:

  • client_secret_basic - client ID and client secret must be provided via Authorization header as described in RFC-6749.
  • client_secret_jwt / private_key_jwt – client_assertion attribute should be used to pass a signed JWT as described in RFC-7523.

For non-confidential client application types the client identifier must be provided via client_id request attribute.

HTTP Method: post Endpoint: /restapi/oauth/token Rate Limit Group: Auth
