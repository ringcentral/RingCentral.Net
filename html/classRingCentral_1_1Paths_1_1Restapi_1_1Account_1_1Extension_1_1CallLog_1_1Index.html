Returns the user's individual call log record(s) by ID(s). Bulk syntax is supported: multiple IDs can be specified as a comma-separated list in {callRecordId} (up to 50 IDs). A single ID returns HTTP 200 with application/json. Multiple IDs return HTTP 207 with multipart/mixed (one status part, then one part per record).
